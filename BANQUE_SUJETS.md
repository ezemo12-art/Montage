# Banque de sujets — DOSSIER 00

Une fiche par affaire. Avant de produire, deux vérifications :
1. **Déjà fait ?** `python3 scripts/sujets.py deja-fait "<affaire ou lien>"` (cherche dans `dossiers/` ET ici).
   Une ligne « prête » ne prouve rien.
2. **Toujours vrai ?** Chaque fait, date et **statut judiciaire** se relit sur une source fiable le jour même.

La data avant les idées : un sujet entre dans le plan quand une vidéo de référence prouve qu'il marche
(lectures ÷ médiane des 24 dernières vidéos du compte). Elle dit qu'un sujet marche ; elle ne donne jamais
son contenu (art. L122-4 CPI) : on refait tout avec nos sources et la voix de l'Archiviste.

## Modèle de fiche

```
## <Nom de l'affaire> — <lieu>, <année>
Statut : à faire / en cours / prête / programmée / sortie
Type : disparition / meurtre non élucidé / affaire judiciaire / escroquerie / mystère / enquête historique
Vidéo de référence : lien ___ · lectures ___ · médiane du compte ___ · ratio ___ × · relevé le __/__
Déjà fait chez moi ? non / oui, DOSSIER-___
Statut judiciaire (vérifié le __/__) : condamné / acquitté / non élucidé / en cours / prescrit
Sources : ___ (presse reconnue, décisions de justice, archives)
Faits à prouver : ___ → source ___, lue le __/__
Personnes nommées : ___ (aucune personne non condamnée présentée comme coupable)
Format : 60–90 s · mot à commenter ___
Créneau : ___
```
