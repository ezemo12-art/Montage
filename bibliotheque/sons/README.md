# Bibliothèque de sons DOSSIER 00 (ElevenLabs, ~50 crédits chacun)

| Fichier | Usage automatique dans `scripts/enigme.py` |
| --- | --- |
| `woosh.mp3` | changement de segment, entrée d'image, zoom sur un indice |
| `impact.mp3` | lignes du hook, bandeaux, étiquettes, chrono, question |
| `tictac.mp3` | pendant le chrono (boucle de 10 s) |
| `montee.mp3` | 2,6 s avant la question |
| `ding.mp3` | appel à commenter |
| `nappe-enquete.mp3` | nappe musicale sous toute la vidéo (boucle de 30 s, volume 0,16) |

Sons propres à une énigme : dans son dossier (`sons/`), déclarés dans `enigme.json` → `"sons"`.
