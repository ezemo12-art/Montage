# REGLES_MONTAGE.md

Cahier des règles permanent de montage pour toutes les vidéos verticales destinées à Instagram Reels, TikTok et YouTube Shorts.

## IMPORTANT

- Lire intégralement `REGLES_MONTAGE.md` **AVANT chaque nouveau montage**.
- Ces règles constituent la direction artistique par défaut du projet.
- Ne pas demander de confirmation pour chaque décision de montage : prendre les décisions nécessaires en respectant ces règles.
- Si une instruction spécifique de l'utilisateur contredit une règle de ce fichier, **l'instruction spécifique est prioritaire**.
- Le résultat doit être directement exploitable et professionnel.
- Le montage doit être pensé pour maximiser la rétention sans donner une impression de montage artificiel ou surchargé.
- Le style de référence est celui du Reel fourni par l'utilisateur : créateur tech / IA / business premium, cinématique, moderne, minimaliste et dynamique.
- Ne jamais copier littéralement le Reel de référence. Reprendre ses principes de réalisation et créer une identité visuelle cohérente pour les vidéos de l'utilisateur.

---

## 1 — FORMAT FINAL

- Vertical 9:16
- 1080 × 1920 px
- 30 FPS
- H.264
- Audio AAC
- Export optimisé Instagram Reels / TikTok / YouTube Shorts.

Tous les éléments importants doivent rester dans une zone de sécurité adaptée aux interfaces des réseaux sociaux.

Ne jamais placer un texte important :

- trop près du haut ;
- trop près du bas ;
- sous les boutons de l'interface ;
- derrière les éléments d'interface des plateformes.

## 2 — DIRECTION ARTISTIQUE GÉNÉRALE

L'identité visuelle doit être :

- premium ;
- moderne ;
- technologique ;
- cinématique ;
- minimaliste ;
- élégante ;
- dynamique ;
- orientée IA / technologie / business ;
- proche des vidéos de créateurs tech professionnels.

Le montage doit donner l'impression d'une vidéo réalisée par un monteur professionnel + motion designer.

Éviter absolument l'apparence :

- template CapCut générique ;
- vidéo TikTok surchargée ;
- montage avec effets aléatoires ;
- gros blocs de texte permanents ;
- animations excessives ;
- transitions extravagantes ;
- emojis partout ;
- couleurs criardes ;
- sous-titres qui occupent la moitié de l'écran.

La règle principale :

> **SIMPLE À REGARDER, MAIS COMPLEXE DANS LE TRAVAIL DE MONTAGE.**

Le spectateur doit trouver la vidéo naturelle alors que beaucoup de travail graphique a été effectué.

## 3 — STYLE DE RÉFÉRENCE

Le Reel fourni sert de référence artistique.

Les caractéristiques à reproduire dans l'esprit sont :

- alternance entre face caméra et éléments visuels ;
- cadrages dynamiques ;
- zooms numériques très légers ;
- captures d'écran ;
- interfaces d'applications ;
- plans d'ordinateur ;
- éléments graphiques flottants ;
- typographie très forte ;
- mots clés courts ;
- animations propres ;
- profondeur et perspective ;
- transitions discrètes ;
- sound design précis ;
- rythme soutenu ;
- esthétique sombre et premium.

Le montage ne doit pas forcément changer de plan toutes les secondes. Il doit plutôt donner constamment l'impression que quelque chose évolue visuellement.

## 4 — DÉRUSH AUTOMATIQUE

Avant tout montage :

1. Transcrire le rush avec Whisper ou le système de transcription disponible.
2. Identifier chaque phrase.
3. Identifier les silences.
4. Identifier les hésitations.
5. Identifier les répétitions.
6. Identifier les erreurs de langage.
7. Identifier les prises multiples.
8. Identifier les mots inutiles : « euh », « hum », « bah », etc.

Supprimer :

- silences inutiles ;
- « euh » ;
- hésitations inutiles ;
- répétitions ;
- erreurs évidentes ;
- débuts de phrases ratés ;
- fins de phrases abandonnées.

Si plusieurs prises existent : garder la **dernière prise complète et naturelle**, sauf si une autre prise est manifestement meilleure.

Règle absolue :

> **NE JAMAIS COUPER AU MILIEU D'UN MOT.**

Éviter également de couper une phrase de façon artificielle. Le résultat doit conserver une diction naturelle.

## 5 — RYTHME

Le rythme doit être dynamique sans être épileptique.

En général :

- changement visuel toutes les 1 à 3 secondes ;
- micro-mouvements fréquents ;
- recadrages lorsque nécessaire ;
- apparition de nouveaux éléments lorsque le discours change d'idée.

Un changement visuel peut être : nouveau plan, zoom, déplacement, texte, carte, capture d'écran, illustration, graphique, logo, interface, animation, changement de cadrage.

Il n'est donc pas obligatoire de changer de plan à chaque seconde.

## 6 — FACE CAMÉRA

Lorsqu'une personne parle face caméra, créer plusieurs cadrages virtuels à partir du même rush :

| Échelle | Usage |
|---|---|
| 100 % | plan normal |
| 105 % | léger zoom |
| 110 % | accent |
| 115 % | moment important |

Les zooms doivent être fluides, progressifs, légers et justifiés.

Éviter les zooms TikTok agressifs. Le visage doit rester correctement cadré. Lorsqu'un passage est particulièrement important, le cadrage peut se rapprocher légèrement.

## 7 — ALTERNANCE DES PLANS

Utiliser autant que possible une structure visuelle du type :

```
FACE CAMÉRA
↓
ZOOM / RECADRAGE
↓
CAPTURE / INTERFACE
↓
FACE CAMÉRA
↓
GRAPHISME
↓
CAPTURE
↓
FACE CAMÉRA
```

Cette structure doit rester naturelle. Ne pas afficher une capture d'écran simplement pour remplir un espace. Chaque visuel doit être lié à ce que dit la personne.

## 8 — RÈGLE FONDAMENTALE DU MOTION DESIGN

**NE PAS simplement écrire à l'écran ce que la personne dit.** Le texte doit compléter le discours.

Exemple — la personne dit :

> « Cette IA peut automatiser une grande partie de ton travail. »

NE PAS afficher : « Cette IA peut automatiser une grande partie de ton travail ».

À la place, afficher une représentation visuelle :

```
IA
↓
AUTOMATISATION
↓
TÂCHES
↓
RÉSULTAT
```

ou une interface / un workflow / une animation représentant l'automatisation.

## 9 — RÈGLE « 1 IDÉE = 1 VISUEL »

Chaque nouvelle idée importante doit avoir une représentation visuelle.

| Idée | Visuel |
|---|---|
| ARGENT | chiffre animé / graphique |
| APPLICATION | mockup de téléphone |
| IA | interface / logo / workflow |
| AUTOMATISATION | processus avec flèches |
| CROISSANCE | graphique |
| COMPARAISON | deux cartes |
| PROBLÈME | élément visuel représentant le problème |
| SOLUTION | élément visuel représentant la solution |
| ÉTAPE | numéro + carte |
| STATISTIQUE | chiffre très visible |

## 10 — CAPTURES D'ÉCRAN

Les captures d'écran doivent être traitées comme des éléments de motion design. Ne jamais simplement poser une capture statique plein écran pendant plusieurs secondes.

Utiliser si pertinent : coins arrondis, ombre, légère perspective, zoom, déplacement, crop, curseur, surbrillance, cercle, flèche, focus sur une zone précise.

Exemple :

```
Capture d'écran → zoom sur un bouton → curseur se déplace → clic → élément apparaît
```

## 11 — PLANS D'ORDINATEUR

Lorsque du matériel vidéo montre un ordinateur ou un écran, utiliser ces plans comme des plans cinématiques.

Possibilités : léger zoom avant, mouvement horizontal, crop, profondeur, focus sur l'écran, transition vers une capture directe de l'interface.

Créer une continuité entre :

```
PLAN ORDINATEUR → CAPTURE D'ÉCRAN → RETOUR FACE CAMÉRA
```

## 12 — TYPOGRAPHIE

Police principale : **Inter**

Graisses : Inter Regular, Inter Medium, Inter SemiBold, Inter Bold, Inter ExtraBold.

Pour les gros mots / titres : **Inter ExtraBold**.

Ne pas multiplier les polices : **maximum 2 familles typographiques**. La typographie doit être très propre et contemporaine.

## 13 — TITRES ET GROS TEXTES

Les gros textes doivent être courts : privilégier **1 à 5 mots**.

Exemples : « GAGNER DU TEMPS », « 3 OUTILS », « AUTOMATISE ÇA », « REGARDE ÇA », « 10× PLUS RAPIDE », « LE PROBLÈME », « LA SOLUTION ».

Ne jamais afficher de longs paragraphes comme élément graphique. Le texte doit être un objet visuel, pas un transcript.

## 14 — COULEURS

| Rôle | Couleur |
|---|---|
| Fond sombre | `#0B0B0F` |
| Blanc | `#FFFFFF` |
| Accent principal | `#FFB800` |
| Accent secondaire | `#FF6B00` |
| Gris | `#A1A1AA` |

La majorité du texte doit rester blanche.

Les couleurs orange / jaune doivent être utilisées pour : mots importants, chiffres, éléments sélectionnés, boutons, indicateurs, animations, éléments destinés à attirer l'œil.

Ne pas colorer tout l'écran. La couleur d'accent doit être rare afin de conserver son impact.

## 15 — CONTRASTE

Toujours privilégier un contraste fort : texte blanc sur fond sombre, texte sombre sur fond clair.

Si un élément est placé sur une vidéo complexe, utiliser éventuellement : fond semi-transparent, blur, carte, ombre, contour discret.

Le texte doit rester lisible même sur un petit écran.

## 16 — SOUS-TITRES

Les sous-titres doivent être synchronisés très précisément avec la voix.

- 2 à 4 mots par bloc (idéalement 2 à 3) ;
- majuscules ;
- Inter ExtraBold ;
- blanc par défaut ;
- mots importants en couleur d'accent.

Exemple : « TU PEUX » → « AUTOMATISER » → « TON ENTREPRISE ».

Les mots doivent apparaître au bon moment. Éviter les sous-titres trop bas. Ne jamais masquer le visage inutilement.

## 17 — ANIMATION DES SOUS-TITRES

Animations possibles : apparition rapide, légère montée, scale, pop, opacity, changement de couleur sur un mot important.

Animation type : **scale 95 % → 100 %**, durée courte, easing naturel.

Ne pas faire rebondir chaque mot de façon excessive. Le spectateur doit lire facilement.

## 18 — MOTS IMPORTANTS

Lorsqu'un mot possède une importance particulière : accent couleur, poids plus fort, taille légèrement supérieure, soulignement animé, badge, petite animation.

Exemple : « Tu peux gagner **10 HEURES** par semaine. » → 10 HEURES devient l'élément graphique principal.

## 19 — CARTES

Les cartes doivent être arrondies, minimalistes, légèrement ombrées, propres et espacées.

**Radius recommandé : 16 à 28 px.**

Contenu possible : logo, chiffre, titre court, icône, capture, statistique, bouton.

Apparition : slide, scale, fade, spring légère.

## 20 — LOGOS

Lorsqu'un outil ou une entreprise est mentionné, utiliser son **vrai logo** lorsque possible.

Ne jamais : déformer, étirer, recolorer arbitrairement, pixelliser.

Présenter les logos dans des cartes propres si nécessaire (ex. [LOGO CLAUDE], [LOGO CHATGPT], [LOGO REMOTION], etc.).

## 21 — GRAPHIQUES

Les statistiques doivent être visuelles. Au lieu de « 70 % des entreprises… », afficher **70 %** avec une animation de compteur ou un graphique.

Les chiffres importants peuvent avoir : scale, compteur, cercle de progression, barre, graphique, badge.

## 22 — ANIMATIONS

Privilégiées : fade, slide, scale, spring légère, mask reveal, wipe, parallax, zoom, déplacement horizontal, déplacement vertical.

À éviter : rotations permanentes, explosions, glitch excessif, transitions 3D inutiles, effets lumineux excessifs.

Chaque animation doit être rapide et élégante.

## 23 — TRANSITIONS

La transition principale doit rester le **CUT**. Les autres transitions uniquement lorsqu'elles apportent quelque chose.

Privilégier : cut, zoom, whip léger, slide, mask reveal, match cut.

Ne pas mettre une transition spectaculaire entre chaque plan.

## 24 — SOUND DESIGN

Le sound design est une partie importante du montage. À utiliser avec parcimonie :

| SFX | Usage |
|---|---|
| WHOOSH | mouvement / transition |
| POP | apparition d'un élément |
| CLICK | interaction / bouton |
| DING | chiffre / information importante |
| IMPACT | moment fort |

Les SFX doivent être subtils. Ils ne doivent jamais couvrir la voix.

## 25 — MUSIQUE

Utiliser une musique moderne adaptée au contenu.

Priorité : 1. Voix — 2. Sound design — 3. Musique.

La musique doit rester en arrière-plan. **Volume indicatif : environ -15 à -20 dB sous la voix.** Utiliser éventuellement un ducking automatique lorsque la personne parle.

La musique doit soutenir le rythme et non attirer l'attention sur elle-même.

## 26 — AUDIO DE LA VOIX

La voix doit être prioritaire. Appliquer si nécessaire : réduction du bruit, EQ léger, compression, normalisation, limiter.

Éviter : saturation, pompage, voix métallique, compression excessive.

## 27 — HOOK

Les 1 à 3 premières secondes sont extrêmement importantes. Supprimer toute introduction inutile.

Éviter (sauf si cela fait partie du storytelling) : « Bonjour tout le monde… », « Salut les gars… », « Aujourd'hui je vais vous parler de… ».

Commencer directement par : une promesse, une information surprenante, un problème, une question, un résultat, une affirmation forte.

Le premier visuel doit être intéressant immédiatement.

## 28 — STRUCTURE DU REEL

Lorsque le contenu s'y prête :

```
HOOK → PROBLÈME → DÉMONSTRATION → EXPLICATION → RÉSULTAT → CTA
```

Mais ne pas appliquer cette structure mécaniquement. Adapter le montage au script.

## 29 — STORYTELLING VISUEL

Le montage doit suivre la progression du discours.

- Le sujet change → changer le visuel.
- Le discours devient important → accent visuel.
- Le discours donne un chiffre → chiffre animé.
- Le discours donne un exemple → montrer l'exemple.
- Le discours explique un outil → montrer l'outil.

Les images doivent raconter la même histoire que la voix.

## 30 — PROFONDEUR ET CINÉMATIQUE

Lorsque les images le permettent, utiliser subtilement : blur d'arrière-plan, profondeur, perspective, parallax, zoom lent, mouvement de caméra simulé.

Mais rester réaliste : le but est une esthétique de créateur tech professionnel, pas un effet « IA ».

## 31 — REMOTION

Le projet doit être construit avec Remotion lorsque Remotion est utilisé dans le workflow.

Créer des composants réutilisables, par exemple : `DynamicSubtitle`, `AnimatedText`, `KeywordHighlight`, `AnimatedCard`, `LogoCard`, `ScreenshotCard`, `StatCard`, `NumberCounter`, `CTA`, `ZoomCamera`, `WhipTransition`, `PopElement`, `DeviceMockup`, `WorkflowDiagram`, `Caption`.

Ne pas réécrire la même animation plusieurs fois : créer une bibliothèque réutilisable.

## 32 — STRUCTURE DU PROJET

Privilégier :

```
src/
  components/
  compositions/
  animations/
  subtitles/
  audio/
  assets/
  fonts/
  data/
```

Chaque vidéo doit être facilement modifiable. Les timings doivent être centralisés autant que possible.

## 33 — TIMELINE

Avant de rendre la vidéo finale :

1. analyser la vidéo source ;
2. transcrire ;
3. nettoyer la voix ;
4. déterminer les coupes ;
5. créer la timeline ;
6. placer les sous-titres ;
7. identifier les mots importants ;
8. identifier les idées principales ;
9. sélectionner les visuels ;
10. ajouter les animations ;
11. ajouter les captures ;
12. ajouter les logos ;
13. ajouter les SFX ;
14. ajouter la musique ;
15. équilibrer l'audio ;
16. rendre une preview ;
17. contrôler la vidéo ;
18. corriger les problèmes ;
19. exporter la version finale.

## 34 — CONTRÔLE QUALITÉ

Avant de considérer la vidéo terminée, vérifier automatiquement :

- [ ] aucun mot coupé ;
- [ ] aucun sous-titre incorrect ;
- [ ] aucune faute évidente ;
- [ ] aucun texte hors écran ;
- [ ] aucun élément caché derrière l'interface ;
- [ ] aucun logo déformé ;
- [ ] aucune image étirée ;
- [ ] aucun chevauchement ;
- [ ] aucun élément trop petit ;
- [ ] aucune animation trop lente ;
- [ ] aucune animation trop rapide ;
- [ ] voix parfaitement audible ;
- [ ] musique suffisamment basse ;
- [ ] SFX suffisamment subtils ;
- [ ] cohérence graphique ;
- [ ] cohérence typographique ;
- [ ] rythme suffisamment dynamique.

## 35 — RÈGLE ANTI-SURCHARGE

Ne jamais afficher simultanément trop d'éléments.

Si l'écran contient déjà une personne, des sous-titres, une capture et une carte, ne pas ajouter encore 5 éléments graphiques inutiles.

La simplicité visuelle est une force.

## 36 — RÈGLE ANTI-TEXTE

Le texte ne doit jamais devenir le contenu principal de la vidéo.

Le texte doit renforcer, résumer, attirer l'attention, structurer. Il ne doit pas simplement transcrire.

## 37 — RÈGLE DE RÉTENTION

Toutes les quelques secondes, le spectateur doit avoir une raison visuelle de continuer : nouveau cadrage, nouvel élément, nouveau visuel, chiffre, animation, changement de contexte, capture, zoom, révélation.

Mais ne jamais créer artificiellement du mouvement sans raison.

## 38 — IDENTITÉ VISUELLE CONSTANTE

Toutes les vidéos doivent sembler appartenir au même univers. Conserver : mêmes polices, même palette, même style de cartes, mêmes animations, même philosophie de sous-titrage, même traitement sonore, même niveau de qualité.

Même si le contenu change, l'identité doit rester reconnaissable.

## 39 — PRIORITÉ ABSOLUE

En cas de doute, appliquer cet ordre de priorité :

1. Compréhension
2. Rétention
3. Qualité de la voix
4. Lisibilité
5. Storytelling
6. Esthétique
7. Effets

Un effet visuel ne doit jamais sacrifier la compréhension.

## 40 — RÈGLE ABSOLUE FINALE

Avant chaque montage, relire entièrement `REGLES_MONTAGE.md`.

Ne jamais ajouter un effet simplement parce qu'il est disponible. Pour chaque élément, se poser la question :

> « Est-ce que cet élément améliore la compréhension, le rythme, la rétention ou l'esthétique ? »

Si la réponse est non : ne pas l'ajouter.

Le résultat recherché est une vidéo qui semble simple, naturelle et extrêmement professionnelle, alors que le montage comporte un important travail invisible de rythme, motion design, sound design et direction artistique.

Le résultat final doit se rapprocher du niveau des meilleurs créateurs tech / IA / business sur Instagram Reels et TikTok.

Le Reel de référence fourni par l'utilisateur constitue la référence esthétique principale pour le rythme, la typographie, les captures, les cadrages, les animations et l'utilisation du motion design.
